Request Codes of the Website
101 – Switching Protocols
This means the connection is changing from regular HTTP to something else, usually a Web Socket. 

200 – OK
The most common one. It just means "request worked fine, here's your data." Almost every normal page load, image, script, and API call that succeeds will show this code.

204 – No Content
The request succeeded, but there's nothing to send back — an empty response on purpose. It's often used for "ping" or tracking-style requests where the server just needs to acknowledge it received something, not return actual data. 

301 – Moved Permanently
The thing you asked for has a new permanent address, so the browser gets redirected there automatically. In the file, a YouTube link written without the "www" gets redirected to the proper "www.youtube.com" version.
