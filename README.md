🍽️ Campus Eats

Campus Eats is a food ordering and delivery platform designed exclusively for college and university campuses. It connects students, faculty, and staff with on-campus canteens, cafeterias, and local food vendors — making it easy to browse menus, place orders, pay online, and track deliveries, all in one place.

📖 About the Project

    Long queues at campus canteens and food courts often waste students' limited break time. Campus Eats solves this by digitizing the ordering process — letting users order ahead, pay online, and pick up or receive their food without waiting in line.

🎯 Aim

    To build a reliable, scalable, and easy-to-use food ordering and delivery system tailored to a campus environment, reducing wait times and improving the overall food-service experience for students, faculty, and staff.

✨ Features
🔐 User authentication (students, vendors, delivery staff, admin)
🍔 Browse restaurants/canteens and menus
🔍 Search and filter by cuisine, price, and ratings
🛒 Cart and checkout system
💳 Online payment integration
📦 Real-time order tracking
⭐ Ratings and reviews
🔔 Order notifications (email/SMS/push)
🛠️ Admin dashboard for vendor and order management
👥 Target Audience

User Type Role
Students Primary users placing food orders
Faculty/Staff Secondary users ordering during work hours
Vendors/Canteens Manage menus and fulfill orders
Delivery Staff Deliver orders across campus
Admin Manages platform, vendors, and disputes
⚙️ System Overview

Campus Eats connects three main actors — customers, vendors, and delivery agents — through a central platform:

Customer browses menu and places an order
Order is sent to the vendor for preparation
Vendor updates order status (accepted → preparing → ready)
Delivery agent picks up and delivers the order (or customer collects it)
Customer receives real-time status updates until delivery is complete
Admin monitors all activity through a dashboard
